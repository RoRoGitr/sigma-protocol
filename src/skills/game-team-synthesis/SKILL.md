# Game Team Synthesis

Open sibling gateway `../game-development/references/catalog.json`, select `team`, and load its workflow reference; author checkout uses `domains/game-development/catalog.json`. Missing detail means no invented contributor policy.

Order: retain independently authored idea packs → select complete same-project source revisions → compare agreements, dissent, and alternatives → record chosen direction and reasons → record unresolved questions and next experiment → add exact dependencies and submit review. Output an explicit synthesis document, never an automatic merge.

Solo is the default. Packs are workspace-visible planning artifacts, not private access control. Do not fix team size, imply hidden inputs were read, or create accounts, employment terms, permissions, or external work. Source revision changes use the existing dependency invalidation path.

This is a proposed adaptation informed by catalog-linked versioned-review research; keep its limits explicit.
