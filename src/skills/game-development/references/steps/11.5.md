# Game adaptation — Step 11.5: Task Handoff

Generated from catalog 1.0.0. Canonical source: `steps/step-11.5-task-handoff`.

Treatment: **conditional** — Conditional in the Protocol: runs when approved PRDs are handed to agents or other people, which includes a solo creator queuing their own work. Game tasks name pre-existing assets, a narrow change, a rollback point, the validator or receipt command to run and the evidence to attach. Placeholders stand in for engine commands until Step 0 pins the engine. No task is 'make it look good'. Engine handoff checklists record licensing of every non-AI dependency.

## Creator questions

- **task-shape**: For each task: which existing asset or scene, what narrow change, what rollback point, which command produces the receipt?
- **dependency-licensing**: Which engine add-ons, packs, fonts, audio or model dependencies does the handoff rely on, and what is each one's license status?
- **unverified**: Which properties remain unverified after this task (collision, navigation, LOD, lightmaps, frame rate, multiplayer)?
