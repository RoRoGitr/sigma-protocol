# Game adaptation — Step 12: Context Engine

Generated from catalog 1.0.0. Canonical source: `steps/step-12-context-engine`.

Treatment: **adapt** — AGENTS.md synthesis and runtime context stay. The game section records experience goals, the hold list and its reasons, the verb inventory, accessibility scoping, asset law (reference pack before modelling, receipts before done), skeleton or rig names, units and scale, the no-editor-MCP-by-default rule and the playtest log location. Agents must not reopen a creator-held decision silently.

## Creator questions

- **agent-law**: Which game rules must every agent read before touching content (reference pack first, receipts before done, units, skeleton names, no editor MCP by default)?
- **held-decisions**: Which decisions are held by the creator and may not be changed by an agent without a recorded revision?
- **evidence-locations**: Where do playtest logs, receipts and idea packs live so agents cite them rather than invent results?
