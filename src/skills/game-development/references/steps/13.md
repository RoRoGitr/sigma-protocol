# Game adaptation — Step 13: Skillpack Generator

Generated from catalog 1.0.0. Canonical source: `steps/step-13-skillpack-generator`.

Treatment: **adapt** — Project skills and agents stay. Game skills wrap the methods in this catalog (discovery, systems, world, art pipeline, audio, technical production, quality planning, team synthesis) plus thin engine adapters (validate-asset, cook, performance-sample) around official CLIs. Skills cite sources by ID and never promote a fashionable tool into law. Role assignments use the planned game roles; a solo creator may hold all of them.

## Creator questions

- **skills-needed**: Which game skills does this project need now (discovery, systems, world, art pipeline, audio, technical production, quality planning, team synthesis) and which are not-applicable with a reason?
- **engine-adapters**: Which official CLIs or IDE integrations will adapters wrap (background DCC scripts, engine commandlets, headless export, test runners)?
- **role-holders**: Who holds game-design-lead, game-art-director, game-technical-director and game-quality-lead? One person may hold all four.
