# Game World Design

Open sibling gateway `../game-development/references/catalog.json`; select only `narrative`, `characters`, `environments`, `levels`, or `interface` named by the catalog. Load generated workflow references; in an author checkout use `domains/game-development/catalog.json`. Without the pack, do not fabricate detailed templates.

Order: state subject and player-facing purpose → upstream dependencies → spatial/story/interaction constraints that apply → affordances, beats, or navigation → accessibility and recovery needs → smallest uncertainty test → review evidence and revision trigger. Output one revisable document per selected subject.

Do not assume 3D, combat, a world map, art freeze, level graph, or engine. A blockout is useful only when spatial uncertainty makes it useful; it may be not-applicable for narrative or audio-only work.

Sources: [Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/). Treat workflow templates as proposed adaptations and retain catalog source attribution.
