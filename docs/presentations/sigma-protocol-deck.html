Rule #1

The AI stops and asks you

Every step is split into phases. Every phase ends with a gate: a question only you can answer.

If you walk away, it pauses. It never decides for you. Loops can grind on work, but they can't answer gates.

The proper way to use it

Do this, not that

  • Go in order. Later steps read earlier files.
  • Give real answers at every gate.
  • Grade every step before moving on.
  • Run /prd-json after Steps 5 and 11.
  • Use /status and /continue to resume.
  • Let loops finish on proof.
  • Skip to code before Step 11 is approved.
  • Let the AI answer its own gates.
  • Move on below a passing score.
  • Treat "the AI says it's done" as done.
  • Paste secrets into prompts or docs.
  • Keep two copies of the same memory.

The Brain

How the system remembers, and gets smarter every time you use it.

Two brains, one habit

Project brain + company brain

Project

Lives in the repo

Built by Steps 12–14. AGENTS.md is the brain every agent reads first. Skills in src/skills/. Memory in .sigma/memory/.

Knows: this product, its rules, its gotchas.

Company

Lives in one vault

A markdown vault every agent and CLI shares. Sessions, decisions, research, people and patterns across all projects.

Knows: what worked, what failed, and why.

One brain per project, one brain for the company. Never a second copy.

Growing it the right way

Brain rules

Tag everything

Every note gets frontmatter: type, date, status, tags.

Link everything

[[wikilinks]] build the graph. Orphans are dead weight.

Inbox first

Not sure where it goes? Drop it in inbox/ for review.

Edit, don't duplicate

Update the note that exists. Two copies drift apart.

Summaries, not dumps

Keep decisions forever. Raw transcripts and logs get tossed.

No secrets, ever

Keys, tokens, .env files never enter the vault.
