# Research: Community Manager Onboarding → Run Track Co1–Co6

**Version:** 1.0.0  
**Updated:** 2026-06-29  
**Sources:** Discord Community Guidelines + Creator Camp (2025), CMX Hub community maturity model, Orbit Model (community-led growth), Exa synthesis on community manager 30-60-90 plans.

---

## Executive summary

Community managers who retain members focus on **first value in 7 days**, not vanity member counts. Mature programs run: audit → welcome → rhythm → moderation → feedback → advocacy.

Sigma **Co-track** is **community operations** — not long-form script production (`/run-content`).

---

## Universal community manager phases

| Phase | Timeline | Outputs | Run step |
|-------|----------|---------|----------|
| Platform audit | Week 1 | Health metrics, admin access | **Co1** |
| Welcome + first value | Week 1–2 | 7-day path | **Co2** |
| Content rhythm | Ongoing | Weekly touchpoints (not scripts) | **Co3** |
| Moderation + escalation | Week 2 | CoC, escalation tree | **Co4** |
| Feedback → product | Ongoing | Triage channel | **Co5** |
| Retention + advocacy | Month 2+ | VIP criteria, referrals | **Co6** |
