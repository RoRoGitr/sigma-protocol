# Game adaptation — Step 7: Interface States

Generated from catalog 1.0.0. Canonical source: `steps/step-7-interface-states`.

Treatment: **adapt** — The full state catalogue with recovery, announcements and focus stays for UI. Games add world and body states: dead, stuck, lost, overloaded, motion-sick, cannot-hear-cue, cannot-read, loading, streaming hitch, disconnected; animation contact states for controlled bodies; puzzle states with reset; audio fail-soft when a bank is missing. Each state has a recovery and an announcement.

## Creator questions

- **world-states**: List the world and player states beyond UI (dead, stuck, lost, loading, streaming, disconnected, overloaded) and the recovery for each.
- **body-states**: For a controlled body, which contact and intermediate states exist (idle, start, stop, turn, jump, land, interact, hit-react, fail) and what does the player see between them?
- **perception-failures**: How does the game detect or let the player fix 'cannot parse the space', 'cannot read the UI' and 'cannot hear the cue'?
- **puzzle-states**: For stateful puzzles or systems, what are the explicit states, the reset path and what a mid-state save restores?

## Sources and limits

- [The Gamer's Brain - GDC talks and book record](https://www.youtube.com/watch?v=XIpDLa585ao) — source-claim. Talk metadata and transcript snippets; not frame-reviewed. Books not read. Neuroscience framing can be over-claimed if used as authority rather than as testable guidelines. Fortnite-scale UX org does not transfer to solo.
- [Xbox Accessibility Guidelines V3.2](https://learn.microsoft.com/en-us/xbox/accessibility/guidelines) — verified-source-text. Official Learn page read (v3.2 published 2023-06-08; page updated 2026-08). Xbox-example-heavy. Explicitly not a legal compliance checklist. Not every guideline body was fully read.
- [Animation in Lyra Sample Game in Unreal Engine](https://dev.epicgames.com/documentation/unreal-engine/animation-in-lyra-sample-game-in-unreal-engine?lang=en-US) — verified-source-text. Official docs extract. Unreal AnimBP commands wrap portable ideas; does not define contact-state art.
- [Saving games (Godot docs)](https://docs.godotengine.org/en/stable/tutorials/io/saving_games.html) — verified-source-text. Full page read by the research seat; URL reconstructed from the page title. Teaching slice, not a production save schema.
- [Sigma Protocol game-development adaptation (architecture decision and integration contract)](../SIGMA-GAME-ADAPTATION.md) — proposed-adaptation. Our proposal, not an external practitioner method. Nothing here proves a game is good. Every phase's evidence must come from an authorized external experiment and a human review, never from the existence of a document.
