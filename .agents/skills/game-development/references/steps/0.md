# Game adaptation — Step 0: Environment Setup

Generated from catalog 1.0.0. Canonical source: `steps/step-0-environment-setup`.

Treatment: **adapt** — The bootloader still detects project mode, validates the runtime and persists state. For a game it additionally records which prototype media are available now (paper, tabletop, spreadsheet, greybox, sprite editor, DCC, engine), pins versions of any tool that is already chosen, and records the playtest capture path. An engine is not required to pass Step 0; unknown stays unknown.

## Creator questions

- **prototype-media**: Which prototype media can you use now without installing anything new (paper, cards, spreadsheet, text, greybox, sprite editor, DCC, engine)?
- **pinned-versions**: For every tool already chosen, what exact version is pinned (engine, official sample, DCC, IDE, middleware)? Write 'not chosen' where nothing is chosen.
- **capture-path**: How will playtests be captured (screen recording, notes template, input logs, photos of a tabletop)?
- **input-devices**: Which input devices and accessibility settings can you actually test with on this machine?

## inputs

- Creator profile (discovery.profile) if it exists
- Existing repository or empty folder
- Installed tools inventory (DCC, engine, sprite or audio editors, capture tools)

## activities

- Detect project mode and run the standard doctor
- Record prototype media availability instead of forcing an engine install
- Pin engine + sample + DCC + IDE versions together when any is chosen (marketplace listings and launcher caches can disagree)
- Create the playtest log location and capture template
- Record which official sample projects open cleanly, if an engine is pinned

## reviewCriteria

- Baseline names the prototype medium available now
- Every pinned tool has an exact version or an explicit 'not chosen'
- No engine was installed or chosen just to satisfy the doctor

## revisionRules

- Changing a pinned version re-opens technical.version-pins and any engine-validation phase that cited the old version
- Adding a prototype medium never invalidates existing documents; removing one flags phases that depended on it
