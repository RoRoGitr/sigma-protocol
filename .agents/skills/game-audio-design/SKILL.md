# Game Audio Design

Open sibling gateway `../game-development/references/catalog.json`, select `audio`, and load its workflow reference; prefer `domains/game-development/catalog.json` in the author repo. Detailed audio method unavailable means no invented pack.

Order: player purpose and cue/event → variation/state/parameter needs → dialogue/localization and captions → accessibility treatment → bus/mix ownership if applicable → delivery target chosen for context → runtime or meter evidence required → review and revision. Output a versioned audio plan and evidence checklist.

Engine-native audio, middleware, and noninteractive delivery are choices, not defaults. Do not claim events, banks, playback, loudness, or mix compliance without runtime or meter evidence.

Sources: [FMOD Studio concepts](https://www.fmod.com/docs/2.03/studio/fmod-studio-concepts.html); [Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/). Tool documentation is source text, not proof.
