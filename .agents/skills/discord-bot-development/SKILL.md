# Discord Bot Development Skill

Build production-ready Discord bots using discord.js v14+ with TypeScript. Covers project scaffolding, slash commands, rich interactions, event handling, and deployment.

## When to Invoke

- Creating a new Discord bot from scratch
- Adding slash commands or interactive components
- Building embed, button, select menu, or modal flows
- Setting up event handlers and gateway intents
- Deploying a bot to production

import { Client, GatewayIntentBits, Collection } from 'discord.js';
import 'dotenv/config';

const client = new Client({
  intents: [
    GatewayIntentBits.Guilds,

  ],
});

## Slash Commands

### Command file pattern

```typescript
import { SlashCommandBuilder, ChatInputCommandInteraction } from 'discord.js';

export const data = new SlashCommandBuilder()
  .setName('ping')
  .setDescription('Check bot latency');

export async function execute(interaction: ChatInputCommandInteraction) {
  const sent = await interaction.reply({
    content: 'Pinging...',
    fetchReply: true,
  });
  const latency = sent.createdTimestamp - interaction.createdTimestamp;
  await interaction.editReply(`Pong! Latency: ${latency}ms`);
}
```

### Command registration

```typescript
import { REST, Routes } from 'discord.js';

const rest = new REST().setToken(process.env.DISCORD_BOT_TOKEN!);

// Guild commands (instant, good for development)
await rest.put(
  Routes.applicationGuildCommands(clientId, guildId),
  { body: commands.map(c => c.data.toJSON()) }
);

// Global commands (takes up to 1 hour to propagate)
await rest.put(
  Routes.applicationCommands(clientId),
  { body: commands.map(c => c.data.toJSON()) }
);
```

## Rich Interactions

### Embeds

```typescript
import { EmbedBuilder } from 'discord.js';

const embed = new EmbedBuilder()
  .setColor(0x5865F2)
  .setTitle('Server Stats')
  .setDescription('Weekly activity report')
  .addFields(
    { name: 'Members', value: '1,234', inline: true },
    { name: 'Messages', value: '5,678', inline: true },
  )
  .setTimestamp()
  .setFooter({ text: 'Generated by MyBot' });
```

### Buttons and Action Rows

```typescript
import { ActionRowBuilder, ButtonBuilder, ButtonStyle } from 'discord.js';

const row = new ActionRowBuilder<ButtonBuilder>().addComponents(
  new ButtonBuilder()
    .setCustomId('approve')
    .setLabel('Approve')
    .setStyle(ButtonStyle.Success),
  new ButtonBuilder()
    .setCustomId('deny')
    .setLabel('Deny')
    .setStyle(ButtonStyle.Danger),
);

await interaction.reply({ embeds: [embed], components: [row] });
```

### Modal forms

```typescript
import { ModalBuilder, TextInputBuilder, TextInputStyle, ActionRowBuilder } from 'discord.js';

const modal = new ModalBuilder()
  .setCustomId('feedback-modal')
  .setTitle('Submit Feedback');

const input = new TextInputBuilder()
  .setCustomId('feedback-text')
  .setLabel('Your feedback')
  .setStyle(TextInputStyle.Paragraph)
  .setRequired(true);

modal.addComponents(new ActionRowBuilder<TextInputBuilder>().addComponents(input));
await interaction.showModal(modal);
```

## Event Handling

```typescript
// events/interactionCreate.ts
import { Events, Interaction } from 'discord.js';

export const name = Events.InteractionCreate;

export async function execute(interaction: Interaction) {
  if (interaction.isChatInputCommand()) {
    const command = interaction.client.commands.get(interaction.commandName);
    if (!command) return;
    try {
      await command.execute(interaction);
    } catch (error) {
      console.error(error);
      const reply = { content: 'Something went wrong!', ephemeral: true };
      if (interaction.replied || interaction.deferred) {
        await interaction.followUp(reply);
      } else {
        await interaction.reply(reply);
      }
    }
  }
  // Handle buttons, select menus, modals similarly
}
```

## Rate Limits

| Scope | Limit |
|-------|-------|
| Global | 50 requests/second |
| Per route | Varies (check headers) |
| Gateway | 120 events/60 seconds |
| Identify | 1/5 seconds |
| Message create (per channel) | 5/5 seconds |
| Reaction add | 1/0.25 seconds |

Always check `X-RateLimit-*` headers and implement exponential backoff.

## Deployment

### PM2

```bash
pm2 start dist/index.js --name "my-bot" --max-memory-restart 500M
```

### Docker

```dockerfile
FROM node:22-slim
WORKDIR /app
COPY package*.json ./
RUN npm ci --production
COPY dist/ ./dist/
CMD ["node", "dist/index.js"]
```

## Security Checklist

- [ ] Bot token in environment variable, never committed
- [ ] `.env` in `.gitignore`
- [ ] Only necessary intents enabled
- [ ] Permission calculator used (not Administrator)
- [ ] Rate limit handling implemented
- [ ] Error boundaries on all interactions
- [ ] Input validation on all user-provided data
