# Projects

Per-project knowledge. Each project gets its own folder with:
- `_index.md` — Project overview and links
- `decisions.md` — Architecture decisions with rationale
- `gotchas.md` — Things learned the hard way
- `concepts/` — Extracted knowledge articles (from compile.py)
